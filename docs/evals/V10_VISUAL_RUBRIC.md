# Rúbrica visual V10 (0–10 por dimensión, promedio simple)

Toda calificación exige **captura de navegador real** y una frase de
justificación. Puntuar desde el código está prohibido (§33 de la espec V10).

| Dimensión | 0 | 5 | 10 |
|---|---|---|---|
| Jerarquía | todo pesa igual | primaria distinguible con esfuerzo | propósito primario obvio en ~2 s |
| Claridad | hay que adivinar | se entiende con contexto | se entiende sin entrenamiento |
| Coherencia | cada pantalla es otra app | familias sueltas | lenguaje NexusMED reconocible |
| Tipografía | escalas al azar | escala con excepciones | escala semántica consistente |
| Espaciado | bordes hacen todo el trabajo | mezcla | el espacio establece la jerarquía |
| Densidad | vacía o asfixiante | desigual | densa donde sirve, serena donde no |
| Interacción | acciones escondidas o todas gritando | primaria clara, resto ruidoso | una primaria por región, recuperación obvia |
| Responsivo | escritorio estirado | usable con fricción | diseño propio por tamaño |
| Accesibilidad | falla crítica visible | AA parcial | AA verificado |
| Rendimiento percibido | saltos y pantallazos | carga con contexto parcial | el layout nunca se pierde |
| Confianza clínica | estados firmado/borrador ambiguos | distinguibles | inequívocos + procedencia inspeccionable |
| Originalidad de marca | plantilla genérica | correcta sin identidad | se reconoce como NexusMED |

**Metas** (§34): críticas ≥ 9.3 de promedio, ninguna crítica < 9.0.

# Rúbrica GENERIC-AI-LOOK (0 = original, 10 = plantilla)

Suma ~1 punto por cada patrón presente de forma dominante: rejilla de
tarjetas sin razón de flujo · gradientes decorativos · todo redondeado ·
círculos de icono arbitrarios · chispas de IA · insignias para metadatos
ordinarios · jerarquía débil · aspecto de librería de componentes ·
estadísticas de dashboard genérico · microcopy inconsistente · sombras sin
capa real · ausencia de interacción distintiva.

**Meta** (§35): ≤ 1.0 en pantallas críticas de Practice.
