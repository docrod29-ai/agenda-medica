# Clinical Decision Records (ADR clínicos)

Un archivo por motor clínico: fuente de verdad, referencia, **unidad canónica**,
política de redondeo, fecha y responsable. Evita que otro developer reimplemente la
fórmula distinto o cambie una unidad sin dejar rastro.

Complementa: `src/lib/clinical/registry.ts` (registro estructurado) y
`docs/audit/regression-ledger.md` (incidentes + tests permanentes).
