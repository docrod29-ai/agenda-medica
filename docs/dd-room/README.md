# Due-Diligence Room (V14 §34)

Sala de evidencia para un comprador técnico. Regla de la sala: **las
debilidades se nombran con su mitigación** — una sala que sólo enseña
fortalezas no es creíble ni útil.

| Documento | Qué contiene |
|---|---|
| `ARCHITECTURE.md` | Arquitectura, invariantes, dónde vive cada cosa |
| `TEST_POSTURE.md` | Postura real de pruebas y compuertas, con números verificables |
| `SCRIBE_EVAL_RESULTS.md` | Resultados Scribe-Eval (hoy: no corrido) |
| `CONVERSATION_EVAL_RESULTS.md` | Resultados Conversation-Eval (hoy: no corrido) |
| `PARITY_PLUS_MATRIX.md` | Puntero a la matriz competitiva con fuentes |
| `KNOWN_LIMITATIONS.md` | Limitaciones conocidas, honestas |

Complementos ya existentes en el repo: `docs/data-room/INDICE.md` (sala de
datos comercial), `docs/audit/regression-ledger.md` (308 regresiones con causa
raíz y prueba), `docs/evals/EXTERNAL_VALIDATION_STATUS.md`.
