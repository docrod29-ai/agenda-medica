# Rúbrica de usabilidad V10

> Spec V10 §36. Tareas sintéticas de médico; se mide, no se opina. Nunca se
> fabrican resultados de competidores no accesibles.

## Métricas por tarea

finalización · tiempo · clics/toques · reversas de navegación · errores ·
estado perdido · recuperaciones · fricción cognitiva (escala 1–5 razonada) ·
entrenamiento requerido.

## Escenarios críticos (spec)

1. Encontrar al siguiente paciente
2. Iniciar consulta
3. Iniciar/detener grabación
4. Recuperarse de una grabación interrumpida
5. Revisar la nota
6. Corregir una medicación
7. Borrador de receta
8. Revisar y cerrar un resultado
9. Buscar un evento longitudinal
10. Volver al contexto exacto
11. Agendar seguimiento
12. Paleta de comandos
13. Acción rápida móvil

Resultados: `agent-state/V10_VISUAL_SCORECARD.json` (sección `usabilidad`).
